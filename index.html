01 — Deep Root System

无界，穿透。

深扎于数字大地之下。当链路被干扰、被封锁、被重写， 庞大的根系会自动探测路径，以极具鲁棒性的底层路由把数据送回枝头。

抗封锁传输

多重隐蔽传输与混淆握手，在链路层完成自适应探测，不依赖单一协议存活。

02 — Leaf Node Clusters

一万个出口，
一种秩序。

树冠上的每一个光点，都是一台独立节点。 分布式模块化把节点集群、分流策略与规则引擎彻底解构，再自动重组。

集群热插拔

单个节点故障无感切换，集群扩容只需要加入，不需要停机。配置在运行中完成重组。

规则引擎

GeoSite 与 GeoIP 双层匹配，应用级策略按需组合，不做无谓的代理解析。

全客户端兼容

一份 YAML，同时适配 Surge、Stash、Loon、Quantumult X、Clash Verge 与 Mihomo 内核。
