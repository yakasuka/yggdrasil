โปรเจกต์นำโดยและดูแลรักษาโดย [yakasuka](https://github.com/yakasuka) ผู้ช่วย AI ต่อไปนี้ได้มีส่วนร่วมในลักษณะความร่วมมือด้านการจัดระเบียบการกำหนดค่า, การเขียนสคริปต์ และงานเอกสาร:

| ผู้มีส่วนร่วม | บทบาท |
| :--- | :--- |
| [Codex](https://github.com/codex) | การจัดระเบียบการกำหนดค่าและการเขียนสคริปต์ |
| [Claude](https://github.com/claude) | ความร่วมมือด้านโค้ดและเอกสาร |

> รายชื่อ Contributors ในแถบด้านข้างของ GitHub รวมจากผู้เขียน commit และผู้ร่วมเขียน `Co-authored-by` Codex และ Claude ใช้อีเมลลายเซ็นของบัญชีทางการ ([`@codex`](https://github.com/codex), [`@claude`](https://github.com/claude)) จึงทำให้ภาพโปรไฟล์และลิงก์แสดงได้อย่างถูกต้อง
