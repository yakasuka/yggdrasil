Проект возглавляет и поддерживает [yakasuka](https://github.com/yakasuka). Следующие ИИ-помощники внесли вклад в работу над конфигурацией, скриптами и документацией:

| Участник | Роль |
| :--- | :--- |
| [Codex](https://github.com/codex) | Организация конфигурации и написание скриптов |
| [Claude](https://github.com/claude) | Совместная работа над кодом и документацией |

> Список Contributors в боковой панели GitHub формируется из авторов коммитов и соавторов `Co-authored-by`. Codex и Claude используют адреса подписи своих официальных аккаунтов ([`@codex`](https://github.com/codex), [`@claude`](https://github.com/claude)), поэтому их аватары и ссылки на профили отображаются корректно.
